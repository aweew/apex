# APEX 市场行为信号中心使用指南

市场行为信号中心用于回答“当前发生了什么、证据是什么、这个行为走到哪一步”。它不是自动荐股工具，也不会直接生成真实买卖指令。页面中的行为结论只用于研究、回测和模拟交易。

## 首次使用

1. 进入“同步”页，确认股票列表和日线已经同步到最近一个完整交易日。
2. 检查日线覆盖率、缺口和任务状态。任务为 `PARTIAL`、日期过期或缺口不为零时，先补跑数据。
3. 进入“策略信号”页，点击“生成策略信号”生成现有 S1/S2/S3 结果。
4. 市场行为计算上线后，点击“计算市场行为”或等待日线同步成功后的自动增量计算。
5. 先用一只熟悉的股票核对 K 线、信号时间和证据，再阅读全市场排行。

## 日常使用顺序

1. **先看数据日期**：确认结果使用的是最近完整 Bar。当天未收盘的日线和未收盘周线只用于观察，不能形成正式确认。
2. **再看市场阶段**：积累、推进、派发、下降表示结构背景，不代表次日必涨或必跌。
3. **查看主要信号**：优先看已确认、强度较高且证据完整的信号，同时核对风险信号。
4. **核对价格结构**：查看信号位置与支撑、阻力、平台、均线和 ATR 距离的关系。
5. **查看生命周期**：区分刚触发、正在确认、已经增强、正在减弱或已经失效。
6. **查看历史统计**：同时阅读样本量、收益分布、最大不利波动和市场环境，不能只看胜率。
7. **再做策略判断**：行为信号只描述事实；需要通过 Strategy Engine 或用户自己的规则转成模拟交易计划。

## 页面各区域

| 区域 | 表示什么 | 怎么用 |
| --- | --- | --- |
| 数据状态 | 行情截止时间、完整性、计算版本 | 日期过期或数据不完整时，降低结论权重 |
| 市场阶段 | 当前价格和成交量结构所处背景 | 用于理解信号处境，不单独作为交易方向 |
| 主要信号 | 当前最有代表性的强势、弱势或确认行为 | 按生命周期、强度和证据完整度排序阅读 |
| 风险信号 | 趋势破坏、过度加速、流动性等风险 | 与主要信号并列看，不用一个总分互相抵消 |
| 排行榜 | 全市场活跃行为的横向比较 | 用类型、阶段、周期和最低强度缩小范围 |
| 支撑阻力 | 摆动点、平台、均线形成的价格带 | 关注价格带和 ATR 距离，不把单个价位视为绝对边界 |
| 行为链 | 前后事件之间的触发、确认、增强或破坏关系 | 判断一个信号是孤立出现还是连续演化 |
| 生命周期时间轴 | 每次状态迁移及其原因 | 查清信号为何确认、减弱、失效或过期 |
| 评分证据 | 每个特征、阈值和贡献值 | 展开核对原始事实，避免只看颜色和总分 |
| 历史统计 | 同规则、同环境的历史条件分布 | 结合样本量和区间，不把历史概率当收益承诺 |

## 核心概念

| 概念 | 含义 | 不代表什么 |
| --- | --- | --- |
| 生命周期 | `OBSERVING -> TRIGGERED -> CONFIRMING -> CONFIRMED -> STRENGTHENING -> ACTIVE -> WEAKENING -> INVALIDATED/EXPIRED` | 不代表固定持有天数 |
| 强度 Strength | 当次行为相对历史窗口有多明显 | 不代表数据可靠度或未来胜率 |
| 置信度 Confidence | 数据完整度和规则在当前场景的稳定性 | 不代表上涨概率 |
| 历史概率 Probability | 同规则在相似历史条件下的条件统计 | 不代表本次一定发生，也不是收益承诺 |
| 风险分 Risk Score | 结构破坏、过热和流动性风险的独立度量 | 不与强度合并成一个万能总分 |
| 支撑/阻力 | 基于摆动点、平台、ATR 和均线形成的价格带 | 不是精确到分的必然反转价位 |
| 日线/周线 | 日线使用完整交易日；周线由完整日线聚合 | 未收盘周线不能形成正式确认事件 |

## 常见行为信号

| 编码 | 用户可见含义 |
| --- | --- |
| S001-S006 | 强势行为，例如放量突破、缩量回踩、趋势延续和结构修复 |
| W001-W006 | 弱势行为，例如放量下破、反弹无量、趋势走弱和结构恶化 |
| C001-C006 | 后续 Bar 对此前触发的确认、增强或失败反馈 |
| R001-R007 | 趋势破坏、过度加速、流动性不足等独立风险 |

具体阈值、确认条件和失效条件以事件记录的规则版本为准。页面显示的中文名称是解释层，审计和回测使用稳定编码。

## 筛选与详情

- **方向/类型**：行为信号使用 `BULLISH`、`BEARISH`、`RISK`；旧策略信号继续使用 `BUY`、`SELL`。
- **生命周期**：研究稳定事件时选 `CONFIRMED` 或 `ACTIVE`；研究早期变化时选 `TRIGGERED` 或 `CONFIRMING`。
- **周期**：MVP 提供完整日线和完整周线。周线未收盘时仅显示观察状态。
- **最低强度**：用于过滤行为明显程度，不能替代置信度和风险分。
- **个股详情**：从排行或列表点击股票，查看 K 线标记、证据、价格带、行为链和时间轴。

## 数据异常与排查

| 现象 | 先检查什么 |
| --- | --- |
| 页面没有信号 | 股票池是否已发布、日线是否至少满足规则窗口、是否排除了 ST 或停牌数据 |
| 信号停留在触发 | D1 至 Dn 确认 Bar 是否已经完整到达，确认条件是否满足 |
| 周线结果变化 | 本周是否尚未收盘；未收盘周线只能作为观察数据 |
| 评分与预期不同 | 规则版本、特征版本、复权口径和 `asOfTime` 是否一致 |
| 排行与详情不一致 | 是否使用了不同日期、周期或缓存；刷新后再核对计算批次 |
| 历史概率为空 | 是否已有足够的同规则、同环境回测样本 |

## 使用边界

- 不使用未完成 Bar 做正式确认，不使用未来数据修正过去事件。
- 没有可靠分钟成交分布时，不把日线成交量解释成真实筹码密集区。
- 信号中心不连接券商实盘。模拟交易只能由用户或 Strategy Engine 基于已确认事件发起。
- AI 只能解释已校验的结构化快照，不参与指标计算，文字结论必须能回指信号和证据。
- 所有输出仅供个人研究、教学和模拟交易，不构成投资建议。
