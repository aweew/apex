# 名词百科扩充实现计划

1. 为基础高频词增加失败测试，覆盖中文常用名、ID 唯一和最低词条量。
2. 在 `terms.extra.js` 补齐交易规则、行情盘口、资金面、公司财务等词条。
3. 在全局导航强化桌面与移动端百科快捷入口。
4. 在主要投研页面用现有 `TermTip` 关联可解释指标。
5. 运行词条测试、前端完整测试和生产构建，再检查改动范围与页面结构。

## 易懂性增强

1. 为通俗解释、高亮分段与相关词条增加失败测试。
2. 给高认知成本词条补充结构化辅助内容，并让搜索覆盖通俗解释。
3. 在百科详情和分享图中呈现通俗解释、重点高亮与相关词条。
4. 清理组件重复属性，完成桌面与移动端视觉验证。
