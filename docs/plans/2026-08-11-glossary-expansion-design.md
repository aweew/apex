# 名词百科扩充设计

## 目标

补齐股票用户每天会遇到的基础名词，并让百科从独立面板变成各投研页面可随手打开的解释层。

## 方案

- 数据层：继续使用 `terms.js` 与 `terms.extra.js`，新增交易规则、行情盘口、资金面和财务基础词，不改变词条结构与查询协议。
- 页面层：继续使用全局 `TermTip`，优先关联行情、板块、自选、持仓、组合、回测、个股和热度页面的标题、指标标签和表头。
- 入口层：桌面右上角入口改为“百科”，移动端顶栏新增独立图标入口；保留 `Ctrl+/` 与菜单内入口。
- 验证层：用查找测试保证常用叫法可命中、ID 唯一，并执行完整前端测试和构建。

## 边界

不自动改写页面文本，不做 DOM 全文匹配，不新增后端接口，也不改变百科弹层和分享功能。

## 易懂性增强

- 难词可增加 `plain` 通俗解释、`highlights` 重点短语和 `related` 相关词条。
- 高亮由文本分段函数生成，页面不接收词条 HTML，避免样式与安全风险。
- 详情按“摘要 → 通俗理解 → 图解 → 正文 → 提示 → 相关词条”阅读，分享图同步输出通俗解释和重点。
