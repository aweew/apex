# 决策可执行性实施计划

1. 新增 DecisionView 结构回归测试，覆盖行动计划、数据状态和模拟买入门禁。
2. 在 DecisionView 增加可执行性、数据状态与行动计划的展示辅助函数。
3. 为桌面表格和移动买入卡片添加行动计划，并为买入清单添加数据状态条。
4. 收紧模拟买入入口，在 UI 和事件处理两层阻止观察项或 RED 数据下单。
5. 运行聚焦测试、前端测试与构建；复查差异和样式。
6. 将历史回放、影子运行和缺失运行模式纳入模拟买入门禁，并以中国市场日期判断当日有效性。
7. 新增决策专用模拟买入接口，服务端重新校验决策动作归属、当日 LIVE 发布状态、数据等级和可执行门禁；决策页买入统一改走该接口。
8. 覆盖历史、非 LIVE、未发布、数据未就绪、未通过门禁和非法目标仓位的服务端拒绝路径。
