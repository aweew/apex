# 看板大盘关键阻力位设计

## 目标

市场立场卡片的辅助信息用于提示大盘当前最需要观察的价格位置。用户进入看板后，可以直接看到上证指数关键阻力位、与当前点位的距离以及突破后的观察动作。

## 数据与计算

- 使用 `index_bar` 中上证指数最近 60 个交易日的日线，不引入新的外部数据源。
- 在当前点位上方寻找左右各 3 个交易日均低于它的波段高点，取距离当前点位最近的一处。
- 暂无已确认波段高点时，使用当前点位上方的近 20 日最高点。
- 当前点位上方没有历史高点或日线不足时不输出点位，由页面显示现有市场仓位建议。

## 展示

有阻力位时显示：`上证指数关键阻力位 3300.00 点，距当前约 3.13%；突破并站稳后再提高仓位。`

市场立场卡片只读取市场级提示；个股操作继续由盘前决策和执行清单承载。
