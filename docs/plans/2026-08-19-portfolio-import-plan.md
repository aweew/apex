# 持仓导入体验实施计划

1. 为批量文本解析、表头识别、校验、序列化和失败行映射增加前端单元测试。
2. 实现纯函数解析工具，统一生成可编辑导入行。
3. 实现独立持仓导入弹窗，覆盖粘贴预览、手工修正、行增删、状态反馈和失败重试。
4. 将组合页旧文本框弹窗替换为新组件，导入完成后刷新组合列表。
5. 运行前端全量测试与生产构建，并在桌面和手机视口执行可视验收。
6. 为截图格式/大小、组合归属、模型 JSON 解析、证券精确匹配、异常行与重复行增加后端测试。
7. 扩展 OpenAI 兼容客户端发送临时图片数据，新增只读截图识别预览服务与 multipart 接口。
8. 为截图选择、拖放、粘贴、识别中状态、预览映射和警告展示增加前端测试与实现。
9. 运行后端聚焦测试、前端全量测试/构建，并再次执行桌面和移动端可视验收。
