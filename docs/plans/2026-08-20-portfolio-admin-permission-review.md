# 管理员组合操作权限代码审查

## 审查结论

管理员可操作任意用户的单个组合，普通成员的写权限仍限定为本人组合。管理员代操作产生的默认持仓镜像与交易流水均归属组合所有者，没有写入管理员账户。

## 已修复问题

1. 使用 `systemDefault` 区分当前用户默认组合与归属用户真实默认组合，关闭默认组合的删除和归档错误入口。
2. 管理员角色在组合列表和详情入口各查询一次，摘要构建不再产生重复角色查询。
3. 移动端持仓行操作按钮扩大到 44 像素，买入、卖出和编辑入口在首屏可达。
4. 编辑弹窗依据正在编辑的组合判断默认状态，不依赖页面当前选中的组合。

## 剩余验证边界

本地浏览器管理员令牌已失效，无法对有真实持仓数据的移动详情执行买卖点击验收。未绕过认证；静态布局、权限回归、全量测试和生产构建均已覆盖。
