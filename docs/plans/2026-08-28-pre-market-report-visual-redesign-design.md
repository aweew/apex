# 盘前研报视觉与决策结构改版

## 目标

把当前按章节平铺的长文改成真正可用于盘前决策的研究简报。首屏应在一次扫读内回答四个问题：今天怎么看、优先看什么、什么会推翻判断、开盘后如何验证。

## 信息结构

1. 顶部使用市场温度、市场状态、核心观点、优先方向和最大风险组成决策摘要。
2. 市场状态与资金风格改为证据矩阵，标签和事实分层展示，不再模拟普通文本表格。
3. 投资机会拆成方向、催化、确认、失效四个明确字段，禁止同一催化机械复制为多个机会。
4. 持仓按处置紧迫度排序；卡片突出仓位、盈亏和处理动作，组合风险集中为摘要网格。
5. 开盘剧本改为偏强、震荡、转弱三种并列情景，方便开盘后快速对照。

## 视觉方向

- 使用研究机构式的纸张底色、深墨标题、蓝色数据强调、金色观点强调和红绿风险语义。
- 控制圆角、阴影和装饰，依靠排版、数字、分隔线和节奏建立高级感。
- 网页与分享长图使用同一个正文组件和相同阅读顺序，只通过密度变量适配载体。
- 移动端保持单列阅读，按钮和卡片内文字不得溢出或互相遮挡。

## 验收

- 解析器能识别机会、情景、持仓和组合风险的结构化字段。
- 网页与分享图不再各自实现章节渲染。
- 同一事件标题在投资机会段最多出现一次。
- 通过前端完整测试、构建、后端聚焦测试和桌面/移动端截图验收。
