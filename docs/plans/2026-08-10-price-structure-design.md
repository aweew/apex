# 个股支撑压力与筹码分布设计

> 依据：微信公众号文章《支撑压力怎么看？均线是动态支撑，筹码密集区是真实支撑》
> 页面：个股详情 `/stock/:code` 的“行情图表”页签

## 目标

- 用均线判断趋势方向，用筹码密集区定位价格区域。
- 同时展示主要支撑、主要压力、平均成本、获利盘比例与集中度。
- 支撑和压力按当前价动态分类，体现突破后角色互换。
- 所有结论可回溯到已有日线，明确这是估算模型而非交易所真实账户持仓。

## 方案

1. 以最近最多 500 根日线建立固定价格桶。
2. 每个交易日先按换手率衰减存量筹码，再把当日新筹码按最低价到最高价的三角分布加入，重心取典型价 `(高 + 低 + 收) / 3`。
3. 对最终分布做轻度平滑并识别局部峰值。当前价下方的峰为支撑，上方的峰为压力；按密度和距离排序选主位。
4. 用 MA5/MA10/MA20/MA60 排列与 MA20 斜率判断偏强、偏弱或震荡，并列出当前价附近的动态均线位。
5. K 线用虚线标记主支撑和主压力；独立面板展示横向筹码柱、当前价和平均成本。

## 边界

- 不新增表和后端接口，直接复用个股详情已返回的 OHLC、成交量和换手率。
- 缺失换手率时使用保守的默认换手参与估算，并在质量说明中披露。
- 少于 20 根有效日线时不输出结构结论。
- 价位是区域而不是精确买卖点；模块固定展示风险提示。
