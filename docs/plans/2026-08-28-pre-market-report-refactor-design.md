# 盘前研报重构设计

## 目标

把盘前研报从数据审计页改成可直接发给投资者阅读的观点稿。读者应在首屏看到今日主线、最大分歧和交易条件，不再看到“关键变量”、事件等级或无投资映射的新闻。

## 内容结构

1. 动态标题：直接概括当天最值得交易的矛盾。
2. 市场状态：用已知成交、涨跌家数和涨跌停说明风险偏好。
3. 资金风格：明确偏强方向、承压方向和资金是否扩散。
4. 投资机会：每项包含当日催化、开盘确认和失效条件。
5. 持仓应对：只展示需要处理的重点持仓和组合集中风险。
6. 开盘剧本：给出偏强、震荡、转弱三种可验证场景。

## 信息门槛

- 没有主题或个股传导链的天气、灾害和普通社会新闻不进入盘前事件。
- 外围行情只能作为 A 股相关方向的催化或风险验证，不能单独构成机会。
- 昨日强势题材只能作为延续候选，开盘量价确认后才升级为主线。
- 缺失数据继续保留在响应元数据中，但不占正文阅读空间。

## 页面与入口

- 主导航删除盘前研报菜单项，路由继续保留。
- 看板“开盘准备”提供完整研报入口。
- 阅读页使用单栏编辑部式排版，正文全展开；持仓继续使用独立卡片。
- 数据覆盖等级、来源和生成时间降到页脚，不与投资观点竞争视觉层级。
