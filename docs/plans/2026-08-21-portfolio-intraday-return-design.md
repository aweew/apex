# 盘中实盘组合收益曲线设计

## 目标

在组合详情中展示当前交易日的日内收益率波动，以 5 分钟为一个数据点。曲线需要能快速回答当前收益率、盘中最高、盘中最低和日内振幅，并保留现有每日收益快照。

## 数据口径

- 行情刷新：交易日 09:30-11:30、13:00-15:00，每 5 分钟刷新一次重点证券实时行情。
- 组合范围：当前启用用户的全部活跃实盘组合，包含默认持仓和非默认组合。
- 日内收益率：沿用组合详情已有口径，即 `当日盈亏 / (当前持仓市值 - 当日盈亏) * 100`。
- 现金：计入总权益，但当日盈亏只来自持仓行情，因此现金不会制造收益波动。
- 时间桶：快照时间向下归并到 5 分钟，组合与时间桶唯一，重跑只更新同一数据点。

## 后端

新增 `portfolio_intraday_snapshot` 表，记录组合、交易日、快照时间、总权益、当日盈亏、当日收益率和持仓数。新增盘中快照服务：调度器完成共享行情刷新后，在正确用户上下文中为其全部活跃组合写快照；查询接口校验组合可见性后返回指定交易日的升序序列。

重点行情集合补入非默认组合持仓代码，避免只有“我的持仓”和观察池证券获得实时价格。

## 前端

组合详情同时加载当日盘中快照。盘中面板展示收益率折线、零轴、正负区域色彩，以及最新、最高、最低、振幅四项摘要。页面停留期间每 5 分钟静默拉取一次盘中数据，切换组合或离开页面时正确重置/销毁资源。

桌面和移动端共用同一数据口径；移动端摘要改为两列，图表缩短并收紧坐标边距，避免横向溢出。
