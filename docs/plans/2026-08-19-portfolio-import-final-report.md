# 持仓导入体验实施报告

## 完成内容

- 新增独立持仓导入弹窗，展示目标组合与新增或更新语义。
- 支持 Excel、Tab、逗号、中文逗号和空格粘贴，并识别常见中文表头。
- 新增可编辑桌面预览表格与移动端记录列表，支持逐行增删和修正。
- 新增本地校验、完整失败原因、部分成功状态和失败行单独重试。
- 导入请求期间锁定可变操作，导入完成后刷新组合数据。
- 支持选择、拖放或粘贴单张券商截图，识别结果进入同一份可编辑预览。
- 新增只读截图预览接口，校验组合归属、图片格式/大小、股票精确匹配、异常数值与重复证券。
- 截图仅作为临时模型请求内容，不保存文件，不在预览阶段写入或删除持仓。
