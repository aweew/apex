# Apex 常用短线选股模板设计

> 状态：已确认
> 目标：在现有策略选股中增加四个可解释、可复盘的常用短线模板，不把候选筛选宣传成完整交易策略。

## 1. 范围

新增“板块共振首板、低位首板、涨停回马枪、缩量回踩”四个系统模板。模板继续采用单策略内全部规则 AND 执行，用户复制后可调整参数。

不新增数据库表，不接入竞价、Level-2 或历史分钟数据，不实现自动下单。板块共振先使用同题材涨停家数作为可验证的联动代理，避免使用无法按历史时点重放的模糊资金标签。

## 2. 方案

两个首板模板复用市场范围、ST、连板层级、封板时间、炸板次数、封单金额、成交额、换手率、价格位置和题材联动规则。

两个日线形态模板新增五类通用指标：距最近涨停天数、最新成交量相对前 N 日均量、最新收盘相对 N 日均线距离、是否突破前 N 日高点、MA5/MA10/MA20 是否多头排列。指标进入统一规则目录、执行器和命中依据，保持系统模板与用户自定义策略一致。

## 3. 数据口径

- 距最近涨停天数：最新日线为 0，向前按交易日计数，主板涨停阈值沿用 9.5%；窗口内没有涨停是正常未命中，不标记为数据缺失。
- 量能相对均量：最新成交量 / 前 N 个交易日平均成交量，结果以百分比表示。
- 收盘相对均线距离：最新收盘价 / 包含最新日线的 N 日简单均线 - 1，结果以百分比表示。
- 突破前高：最新收盘价严格高于此前 N 个交易日最高价。
- 均线多头排列：MA5 > MA10 > MA20。

数据不足或成交量无效时规则不命中，并返回明确的数据缺失原因。

## 4. 模板边界

- 板块共振首板、低位首板依赖当日实时截面与当日涨停池，属于实时候选过滤。
- 涨停回马枪、缩量回踩使用完整日线形态，运行模式标记为收盘。
- 模板只产生候选，不代表入场信号；用户仍需结合次日触发、结构止损、板块退潮和最大持有期制定交易计划。

## 5. 成功标准

- 系统模板总数增加四个，名称、运行模式和关键规则正确。
- 五个日线指标覆盖正常值、边界值和数据不足情况。
- 新规则可保存、复制、编辑、执行，并在命中依据中展示实际值。
- 后端聚焦测试、前端测试、构建和差异检查通过。
