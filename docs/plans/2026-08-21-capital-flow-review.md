# 资金面与龙虎榜代码审查

## 结论

通过。北向资金、个股主力资金流、板块净流入和龙虎榜已经形成从采集、快照落库、调度、查询接口到前端展示的完整链路，未发现阻断交付的问题。

## 关键校正

- 北向资金公开字段缺失时保存最新交易日并标记 `NOT_DISCLOSED`，不把缺失值展示为 0，不回退旧交易日，也不根据成交额推算净买入。
- 所有金额统一按元落库；北向接口的亿元值在采集层转换，个股资金流与龙虎榜保持源数据的元口径。
- 盘中调度使用内部 `stock` 模式，只刷新个股资金流；北向历史接口仅在 15:10 和 18:20 请求，降低无效调用频率。
- 板块资金复用 `sector_quote.net_inflow`，避免重复建设板块快照和查询逻辑。
- 各数据集独立提交；数据源为空或失败时保留已有快照，页面展示交易日、同步时间和披露状态。
- 手动刷新接口仅暴露 `flow`、`lhb` 和 `all`，内部 `stock` 模式不对外开放。
