# 决策可执行性设计

## 目标

将买入清单从分散的信息列调整为可执行的行动说明。用户应能在同一位置确认该标的是否可执行、建议仓位、参考价、退出边界和当前市场数据状态。

## 范围

修改 `DecisionView.vue`、模拟盘专用下单入口及其回归测试，复用现有 `DecisionTodayResp`、`DecisionItemResp`、`DailyAction`、`DecisionRun` 和 `MarketBriefingResp` 字段。不会新增评分、收益预测、新闻情绪判断或数据库字段。

## 行动规则

`executableHint=true` 且市场数据等级不为 `RED` 的买入建议可进入模拟下单。其余买入建议保持可见，标记为“仅观察”，并禁用模拟买入。`YELLOW` 表示保留执行能力，但明确提示需要复核；`RED` 统一阻断模拟买入。

页面不能单独作为授权边界。决策页买入统一调用 `/api/paper/from-decision`；服务端按当前用户重新读取 `DailyAction` 与 `DecisionRun`，仅允许当前中国市场日期、`BUY`、`executableHint=1`、`LIVE`、`SUCCESS`、`published=1`、且数据等级为 `GREEN/YELLOW` 的运行创建模拟单。用户明确输入的目标仓位必须大于 0 且小于 1；留空时采用决策建议仓位，再继续走既有模拟盘风控与撮合。

## 展示规则

买入表格和移动端卡片都展示行动计划：执行状态、建议仓位、参考价和止损止盈或离场规则。买入清单顶部展示市场数据等级及决策/行情截止时间。该状态描述数据可用性，不暗示收益概率。

## 验收

1. 桌面端与移动端均有行动计划展示。
2. 数据状态包含等级和可用截止时间。
3. 非可执行或 RED 数据等级的买入建议无法触发模拟买入。
4. 已有卖出、持有、筛选与新闻展示不变。

## 历史回放边界

只有已生成、决策日为中国市场当日且运行模式为 `LIVE` 的结果才可执行。历史日期的既有 LIVE 运行、`REPLAY`、`SHADOW`、未生成结果以及缺失运行模式的结果均属于只读复盘，必须阻止模拟买入并说明原因。
