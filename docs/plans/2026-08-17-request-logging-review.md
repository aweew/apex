# 全局接口请求日志代码审查

## 结论

未发现阻断或重要问题。实现使用单一过滤器替换两个旧拦截器，异常路径通过 `finally` 收尾，MDC 在请求结束后清理；JSON 请求体只在已知且不超过 64 KiB 时缓存，超限请求不读取。

## 已核对风险

- 敏感信息：密码、Token、密钥、签名、验证码完全隐藏；手机号、身份证和卡号部分隐藏；非法 JSON 不打印原文。
- 日志注入：客户端 traceId 仅接受安全字符和限制长度，手机号进入 MDC 前只保留数字。
- 兼容性：请求体包装后的内容可被后续链路完整读取；Bot HMAC 过滤器位于其后，可继续读取相同请求体。
- 性能：新登录会话直接读取 Sa-Token 中的手机号；存量会话仅首次按用户 ID 回查并回填。
- 分级：HTTP 4xx/5xx 和全局异常标记共同决定 INFO、WARN、ERROR，兼容业务失败仍返回 HTTP 200 的现状。
- 文件日志：控制台保留 ANSI 颜色；滚动文件不写颜色，WARN 和 ERROR 均进入错误日志。

## 验证

- `mvn -q clean test`：461 项通过，0 failure，0 error，0 skipped。
- 定向测试：请求日志 4 项、登录会话 3 项通过。
- `xmllint --noout` 与 `git diff --check` 通过。
- 本地 `18080` 实际请求验证 traceId 生成/透传、手机号与密码脱敏、INFO/WARN 颜色和结束耗时。
