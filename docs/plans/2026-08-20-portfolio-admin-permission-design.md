# 管理员组合操作权限设计

管理员可以编辑、删除、买入、卖出、导入、刷新和打快照任意组合，普通成员仍只能修改自己的组合。组合列表与详情中的 `editable` 统一反映该规则，前端不自行推断权限。

管理员代操作时，默认持仓镜像和交易流水仍归属于组合所有者。管理员查看他人的默认组合时，组合名称和“默认组合”标识也保持所有者视角，不显示成管理员自己的“我的持仓”。

接口使用 `systemDefault` 单独表示组合是否为归属用户的真实默认组合。前端依据该字段隐藏删除和归档入口，避免管理员对他人默认组合看到后端必然拒绝的操作。

移动端详情顶部提供当前组合的买入入口；每只持仓在首屏个股单元格内提供买入、卖出、编辑和观察菜单。原表格尾部操作列仅在桌面端显示，避免要求移动端横向滑动到最右侧。
