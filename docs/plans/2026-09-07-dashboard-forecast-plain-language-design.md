# 看板今日预测直白化设计

## 目标

将今日预测中的总判断、方向依据和开盘后观察条件全部改成普通用户可以直接理解的结论。每句话必须回答实际发生了什么，或接下来具体看什么，不能用投研术语代替结论。

## 设计

- 保留现有海外、亚太和 A 股板块数据判断条件，不改变方向筛选及交易规则。
- 开盘判断直接写“变化不大、偏弱、低开、偏强”和“各板块可能有涨有跌”。
- 方向依据统一写成“最近 3 个交易日上涨或下跌多少、最近 5 个交易日上涨或下跌多少、最近一个交易日上涨或下跌多少”。
- 关注条件直接写“开盘后不明显回落再关注”，回避条件直接写“等到不再下跌且重新上涨后再看”。
- 将专业的市场宽度说法改成“上涨股票是否多于下跌股票”，将原盘中条件标题改成“开盘后看什么”。
- 页面返回文案禁止出现抽象判断、证据标签和交易圈黑话。

## 验收示例

预计开盘变化不大，之后各板块可能有涨有跌。开盘后先看 CPO 概念和液冷服务器，继续上涨再关注；暂时回避科技成长。
