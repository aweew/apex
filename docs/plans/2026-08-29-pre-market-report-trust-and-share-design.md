# 盘前研报可信度与分享效率优化

## 目标

在不扩充正文篇幅的前提下，让盘前研报先回答数据是否新鲜、结论依据是否一致、现有持仓先处理谁，并让分享图在手机聊天窗口中仍能快速阅读。

## 设计

1. 市场温度只使用情绪分对应的统一档位，后端同时输出分数和档位；市场证据段不再重复另一套状态标签。
2. 标题下方前置目标交易日、行情截至日、生成时点和数据覆盖等级；非交易日提前生成下一交易日报告时明确标注“预生成”。
3. 保存用户上一份不同交易日的报告快照，比较投资机会方向并输出新增、延续和降级变化；没有历史快照时不展示。
4. 持仓继续按风险等级和仓位排序，并显示处理顺序。分享图只保留前三项持仓，完整网页仍展示全部重点持仓。
5. 分享图只保留投资机会、持仓应对和开盘剧本，按分享顺序重新编号，正文最小字号提高到 10px。
6. 规则版机会的确认和失效条件增加 9:45 时间窗、板块成交同比和相对沪深 300 强弱，确保开盘后可以核验；AI 提示词同步收紧。

## 边界

- 上一份报告仅使用 Redis 用户级快照，不新增数据库表；首次生成或快照过期时不展示较前日变化。
- 分享图是核心摘要，不替代站内完整研报。
- 本次不改变持仓建议的业务规则，只把现有风险排序转成明确的处理顺序。

## 验收

- 同一情绪分在标题区和市场证据中使用同一档位。
- 周末预生成报告能看到目标交易日、行情截至日和数据覆盖等级。
- 有上一交易日报告时展示新增、延续、降级方向。
- 分享图章节连续、最多三只持仓、无 8px 正文字号。
- 前后端聚焦测试、完整前端测试和构建通过，并完成桌面与移动端截图检查。
