# 隔夜中国资产数据补全设计

## 目标

盘前晨报必须明确提供纳斯达克中国金龙指数、代表性中概股和富时 A50 期指，不得把采集失败误写成市场没有数据。

## 数据契约

- 纳斯达克中国金龙指数使用腾讯行情代码 `usHXC`，作为独立字段返回，不混入美股三大指数。
- 中概股使用独立代表池，覆盖电商、互联网平台、出行、文娱和金融科技；响应保留全部有效报价，主题统计继续输出中位数、涨跌家数和领涨领跌股。
- 富时 A50 期指使用新浪全球期货代码 `hf_CHA50CFD`，按最新价相对前结算价计算涨跌幅，并保留源行情日期时间。
- 新浪该公共行情端点当前仅 HTTP 可稳定访问，请求不携带认证或用户数据；报价仅作为外盘参考，采集或解析异常直接判为缺失。后续应替换为支持 TLS 的授权行情源。
- 三类数据分别进入盘前研报缺失清单；任何已配置行情缺失时，晨报数据等级不得为 `GREEN`。

## 展示

看板在隔夜三大指数后直接展示“中国资产”，首行并列中国金龙指数与 A50 期指，随后展示按绝对涨跌幅排序的代表中概股。报价同时显示源行情时间，所有缺失项显示明确的“暂未获取”。

## 兼容性

新增响应字段保持向后兼容；后端 Redis 晨报缓存、盘前研报缓存和前端本地看板缓存同时升级版本，避免旧缓存被误判为新契约数据。
