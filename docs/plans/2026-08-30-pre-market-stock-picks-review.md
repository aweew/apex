# 盘前研报个股观点审查

## 结论

任务相关差异未发现阻塞问题。研报在存在目标交易日真实候选时，会把首选股票、主观观点、已知依据、触发和失效条件前置；没有候选时保留原板块机会结构，不编造个股。

## 审查要点

1. 目标交易日决策且 `hasToday=true` 时直接形成正式首选；尚未生成目标日决策时，仅允许行情截至日恰好为前一交易日的已生成决策进入“观察首选/观察备选”，不得写成已经可以买入。
2. 当日决策不足三只时，只用目标交易日由智能决策更新、`BUY` 方向且状态为 `TRIGGERED/NEAR` 的候选补充；来源说明、触发条件和失效边界必须完整。
3. `executableHint` 不再被解释为开仓门禁已通过，触发条件统一要求开仓门禁实际为可执行。
4. AI 个股行必须逐只匹配名称、代码、级别、观点、依据、触发、失效和仓位；虚构或改写事实时回退规则版。
5. 个股条目在网页、移动端和分享长图使用同一解析器与渲染组件。
6. 较前日变化明确区分“新增推荐、延续推荐、退出推荐”和板块方向变化，不混用模糊标签。
7. 非正建议仓位不展示；“数据不足”等无效估值标签不进入主观观点或证据。

## 验证边界

视觉验收使用本机隔离 Mock API 和虚拟登录，验证真实前端路由、组件、分享弹窗及响应式布局，不代表线上账号、线上模型输出或生产数据已经验收。
