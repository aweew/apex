# 持仓导入体验代码审查

## 结论

本次持仓导入改动未发现阻断问题。

## 已检查风险

- 导入语义沿用后端同代码新增或更新，不引入隐式删除。
- 本地校验覆盖空证券、数量、成本价和重复证券，失败原因保持在对应行。
- 部分成功后只序列化未成功行，避免重试时重复写入成功持仓。
- 请求进行中锁定粘贴、编辑、增删和关闭，避免响应映射到变化后的行。
- 截图预览接口先校验组合可编辑权限，只识别和校验，不调用持仓保存、删除或快照逻辑。
- 截图限制为 PNG/JPEG/WebP 和 8 MB，并校验 MIME 与真实文件签名；图片和识别原文均不写日志、不落盘。
- 模型结果按代码或完整名称精确匹配股票库；无唯一匹配、数量/成本异常和重复证券在确认前阻断。
- 新截图开始识别时清空旧草稿与旧预览，避免识别失败后误提交上一次结果。
- 移动弹窗正文独立滚动，底部操作栏保持在视口内。

## 范围说明

工作区同时存在组合页桌面滚动规则与对应测试的并行变更；该变更不属于本次持仓导入实现，已原样保留。

## 剩余风险

- 自动化测试使用模拟模型响应，未向外部模型发送真实金融截图；不同券商版式仍需用脱敏样例持续补充识别评估。
