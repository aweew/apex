# 名词百科扩充审查

## 结论

未发现阻断或主要问题。实现复用现有词条结构、全局 `TermTip` 和百科弹层，没有新增接口或改变路由契约。

## 已修正

- “市值”从流通市值歧义中拆出，默认指向总市值。
- “换手率”默认指向个股换手率，模拟盘口径改用明确别名。
- 移除把“价格笼子”与日涨跌幅限制等同的不准确别名。
- 为夏普、Beta、最大回撤、VaR、MACD、前后复权、盘口资金等 25 个理解成本较高的词条补充通俗解释，并只标记 2～3 个关键短语，避免整段高亮影响阅读。
- 相关词条使用有效 ID 关联；切换词条时会清空旧搜索和分类条件，并同步列表选中状态与详情滚动位置。
- 悬浮提示与分享图同步使用通俗解释，分享图同时保留重点短语和相关词条，避免站内外口径不一致。

## 验证

- 词条 ID 唯一，常用中文别名可精确查找。
- 页面共有 93 个百科关联，分布在 19 个视图或组件文件，未发现无效 term ID。
- 25 个通俗解释词条的重点短语均能在内容中找到，相关词条 ID 均有效。
- `npm test` 共 53 项通过，`npm run build` 与 `git diff --check` 通过。
- 桌面 1440×900、移动 390×844 的入口、面板边界、相关词条跳转和分享预览已在浏览器验证；详情区无横向溢出，移动端相关词条按钮高度为 40px。
