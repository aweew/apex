# 盘中实盘组合收益曲线评审

## 结论

未发现阻断问题。实现满足 5 分钟行情刷新、组合盘中快照、用户归属写入、共享组合查看和响应式曲线要求。

## 已核对风险

- 调度器先刷新全局去重行情，再按用户上下文写快照，非默认组合代码不会遗漏。
- 单个用户快照失败不会阻断观察池重估，也不会影响其他用户。
- 快照时间向下归并为 5 分钟桶，同一组合同一时间桶更新而非重复插入。
- 盘中计算使用轻量组合摘要，不触发详情页的技术研判、ATR 和深度 enrich。
- 查询遵循现有共享组合可见口径，写入只允许组合归属用户。
- 页面轮询只更新当前组合，隐藏标签页不请求，切换组合会丢弃旧响应，卸载时清理定时器和图表。
- 空数据有稳定占位，桌面和 390px 移动端均无横向溢出，控制台无错误。
- V47 表和 11 个字段均有数据库 COMMENT，唯一键保证时间桶幂等。

## 剩余边界

盘中自动数据依赖现有 `auto_sync_enabled=true` 和调度器实例启用。代码已完成但尚未提交、推送或部署应用进程。
